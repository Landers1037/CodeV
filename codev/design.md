# CodeV UI 设计规范（简约拟态）

## 设计目标
- 视觉：简约、轻拟态（柔和阴影、克制高光、强调层级）
- 交互：清晰可预测，减少噪音，重要操作可被快速发现
- 统一性：圆角/阴影/间距/动效全局一致

## 布局与结构
- 顶部：自绘标题栏 + 顶部图标菜单（主导航）
- 内容区：路由页面切换（首页/下载/终端/设置）
- 禁用系统标题栏（Windows 原生最小化/最大化/关闭按钮隐藏）

## 圆角规范
- 顶部菜单按钮：圆形按钮，圆角 50%
- 页面内卡片/面板/弹窗：圆角 16px
- 输入框/小按钮：在 16px 基础上递减（例如 10–12px）

## 阴影与拟态
- 基础卡片：轻阴影 + 边框（避免过强投影）
- 悬浮态：阴影略增强，同时背景/边框轻微提亮
- 按压态：阴影减弱 + 轻微下沉（translateY/scale）
- 深色模式：阴影更克制，优先通过明度差与边框体现层级

## 色彩与主题
- 支持明亮/暗黑两套主题，按 CSS class 切换（`dark`）
- 主题色用于强调主操作与进度
- 边框与分割线：低对比度（避免硬切割）
- 禁止在内容区大面积使用纯黑/纯白；使用略偏灰的背景更耐看

## 顶部图标菜单
- 仅图标展示；鼠标 hover 显示文本提示（Tooltip）
- 图标尺寸：16px；按钮尺寸：36px（9 * 4）
- 当前激活态：背景高亮（accent），保持可识别

## 动效规范
- 页面切换：淡入 + 轻微位移（低幅度）
- 按钮：hover 过渡 150–200ms；按压 80–120ms
- 弹窗：fade + zoom（低幅度）
- 避免大幅度弹跳动画，保持“工具感”

## 交互与可用性
- 所有可点击区域需有 hover/active 状态
- 禁用态必须明显（降低透明度 + 禁止 hover）
- 长文本截断（工具安装路径等）并支持复制/打开目录

## Windows 细节
- 可拖拽区域：顶部标题栏区域（`-webkit-app-region: drag`）
- 按钮区域：必须 `no-drag`，避免误拖拽
- 关闭行为可配置：关闭最小化到托盘 + 托盘右键“退出”
